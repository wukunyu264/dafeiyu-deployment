# 截图目录

这里后续放**脱敏后**的运行截图，建议至少三张：

1. **架构落地** —— 后台首页 / 插件列表（插件名可见，但不含凭据）
2. **记忆生效** —— 聊天记录里「她记得你之前说过的事」的对比（QQ 号、头像、昵称都要打码）
3. **自研插件** —— 发链接后她的总结回复，或问天气/热搜的回复

## 打码清单（上传前逐项确认）

- [ ] QQ 号、群号、昵称、头像
- [ ] 机器人昵称与个性化签名（若涉及真人信息）
- [ ] API Key、Token、WebUI 地址与端口（若暴露公网 IP）
- [ ] 聊天里出现的真实姓名、地址、手机号
- [ ] 任务栏里的私人文件名、浏览器标签页

## 提交方式

图片放本目录，然后从上到下改 `.gitignore` 里最后一段（默认忽略 `screenshots/*.png` 等），确认打码无误后再单独提交。

> 建议：能不放截图就不放；用文字描述 + 架构图同样能说明问题，且零泄露风险。
